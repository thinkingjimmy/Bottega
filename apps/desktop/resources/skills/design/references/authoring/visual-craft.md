# Review the delivered composition

Use the saved image and requested use case as the basis for a correction. Review at the scale
the user will see, then inspect the details that affect that task.

| Evidence | Decision |
| --- | --- |
| Main content or action is hard to locate | Adjust hierarchy in the selected source without changing unrelated meaning |
| Content clips at a required viewport | Correct the responsible layout; inspect that viewport again |
| Product colors/type differ from captured source | Restore the identified literal or label the deliberate proposal |
| A control lacks a visible state or usable label | Add the state required by the brief and inspect its appearance |
| A Page object overlaps board content unintentionally | Correct its model bounds in the appropriate coordinate space |
| A screenshot or mount is missing | Keep the visual claim unverified |

For responsive output, inspect the relevant desktop/mobile sizes instead of inferring behavior
from one viewport. For a fixed board, check its declared dimensions and overflow. A Canvas Page
composition and a board's internal layout are distinct surfaces.

Use the separately attributed craft material only for a concrete issue: for example,
[accessibility](../craft/interaction/accessibility-baseline.md),
[color](../craft/foundations/color.md) or
[grouping](../craft/composition/laws-of-ux.md). It supplies advice, not replacement authority for
user values or captured product tokens.

Keep a correction proportional to the requested change. An advisory style finding does not
authorize rewriting every board, replacing the system or fabricating product facts.
Save the source correction through the [document transaction](../formats/document.md), then
inspect the new saved image. Report the actual inspection and any interaction checks still open.
