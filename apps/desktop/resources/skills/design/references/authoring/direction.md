# Turn the brief into document choices

Resolve these decisions from the user request and existing source:

- Is this a new document or a revision of a named saved result?
- What content and action must the intended viewer find first?
- Is the result a responsive board, a fixed device/print board, or a Canvas arrangement?
- Which source, fixed system and local assets supply the product facts?

Only ask about a missing decision if different answers would materially change the result.
Use an already selected reference, brand or system directly. If the user authorized a reasonable
assumption, state it once and continue. Missing factual content remains visibly provisional.

For a requested comparison, place alternatives in the same document with stable board IDs and
clear titles. Pages can group scenarios, but do not create a new document or revision merely to
name an alternative. Let the requested comparison determine how many boards are useful.

Choose board mode and viewport for the real output. A responsive board should tolerate more
than its recorded viewport; a fixed board should use the recorded bounds deliberately.
The current Canvas camera is only a viewing choice and cannot define export dimensions.

Use the saved result to assess the choice. Inspect the relevant board/viewport, identify any
assumptions and keep the user's requested scope as the completion criterion. Refer to
[visual checks](visual-craft.md) for presentation issues and
[source facts](code-grounding.md) for product fidelity.
