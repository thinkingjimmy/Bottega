# Contract decisions

- design_check stays pure; design_commit alone owns ordinary file publication. Initial extract
  save and system edits delegate to that same recoverable journal, not a second registry.
- Separate `design_system_check` and asset-import tools are not added. Only the real scoped
  extract/diff/update/bind/compile tools are named; Chat/workspace/generation comes from the lease.
- All source bytes, themes, aliases, usage and unmounted components remain visible. Unsupported
  values are retained as data and reported, not silently changed or executed.
- CSS is generated from authoritative tokens/aliases. Exact source colors outrank style advice;
  contrast changes are proposals or explicitly authorized additions.
- Components use captured source and pinned local compilation. Remote React/CDNs, package
  hooks and runtime installation are excluded. Mounted evidence and static fallback remain distinct.
- Consumers hold a fixed system revision and complete local closure. Source updates compare
  baseline/current/incoming; deletion and user override conflicts require explicit choices.
- Private preview addresses, automatic send, clipboard fallback, implicit connectors, viewer
  retargeting and the upstream migration/cover requirements are not runtime assumptions.
